# CommonGround

Website for **CommonGround**, a nature foundation, a stichting, being set up together with two collaborators.

## Mission
Using technology to conserve and understand nature.

## Context
Intended to connect to ongoing doctoral research, WildBotics at SDU: work carried out during the PhD should be able to continue professionally under the foundation afterwards.

## Capabilities
- GIS, mapping, and spatial data
- Data analysis
- Applied technology for conservation and ecological understanding

## Status
Greenfield; this repo is the foundation's public site. Web stack not yet chosen; Node tooling assumed for now.

## Related
- CommonGroundResearch: the foundation's R&D work; first project is Endangered.
